# Weight Management (web app)

Live at: https://poker1410.github.io/calorie-tracker-web/

Open in Chrome on Android → ⋮ → **Add to Home screen** (or **Install app**).

- Works offline after the first load.
- All data stays in the browser on the phone. Nothing is sent anywhere; this repo holds only the app code.
- Clearing Chrome's site data for this site deletes the log, so use **Settings → Save backup file** now and then.
